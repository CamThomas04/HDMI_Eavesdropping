Horizontal Blanking Interval: The pixels transmitted at the end of each line that encode non-image related data

Vertical Blanking Interval: The pixels at the end of each frame that indicates the start of a new frame

Pixel Clock Frequency: The symbol rate at which pixels are transmitted over the cable

Line Rate ($f_h$): The number of horizontal lines tranmitted per second

Line Period ($f_h^{-1}$): The time that passes between transmitting a pixel and the one directly beneath it

Frame Rate ($f_v$): The number of complete image frames transmitted per second
